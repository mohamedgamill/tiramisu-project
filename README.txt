# مشروع مدير مخزون وحسابات التيراميسو

## محتويات المجلد
1. `index.html`: التطبيق الكامل لإدارة مخزون الخامات، الخصم التلقائي عند إنتاج العلب، وتنبيهات النواقص (يعمل مباشرة على الموبايل أو الكمبيوتر بدون إنترنت).
2. `مقادير_وتكاليف_التيراميسو.csv`: جدول المقادير والتكاليف لكل علبة ودفعة 60 علبة (يفتح ببرنامج Excel).

## طريقة التشغيل
1. فك الضغط عن الملف المضغوط `tiramisu_project.zip`.
2. افتح ملف `index.html` بأي متصفح (Chrome أو Safari أو Edge) على الموبايل أو الكمبيوتر.
3. سيحفظ المتصفح رصيد مخزونك وسجل الإنتاج تلقائياً على جهازك.
